Set up the admin page

Do this once. It locks your GitHub token with the admin password, so afterwards everyone just types the password. Run it again any time to change the password.

  1. Create a GitHub token: Settings → Developer settings → Personal access tokens → Fine-grained tokens, only for the gokarma-website repository, with Contents and Pull requests set to "Read and write".
  2. Paste it below and choose the admin password.
  3. Use a long passphrase, e.g. four or five random words. Anyone with the password can change the website.
