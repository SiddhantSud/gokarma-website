# Aangan by GoKarma Living — logo kit

Every SVG has its lettering converted to shapes, so it needs no fonts and renders identically anywhere (`<img>`, CSS background or inline).
PNGs are transparent, about 2000 px on the long side (app icon 1024 px).

## Folders
- `clean/` — smooth edges. **Use these on the website.**
- `letterpress/` — the same logos with the hand-pressed ink texture, for print, social and hero art.
- `favicons/` — browser and home-screen icons.

## Which logo where
| Use | File |
|---|---|
| Site header / navbar (light background) | `aangan-lockup-horizontal` |
| Site header on dark or photo background | `aangan-lockup-horizontal-reversed` |
| Footer, narrow columns, mobile menu | `aangan-lockup-stacked` (or `-reversed`) |
| Text-only spots (captions, credits) | `aangan-wordmark` (or `-reversed`) |
| Hero / about section / badges | `aangan-seal-full-colour` (min 96 px wide) |
| Seal on dark backgrounds | `aangan-seal-reversed-for-dark-backgrounds` |
| One-colour seal (stamps, overlays) | `aangan-seal-one-colour-maroon` / `-terracotta` / `-cream` |
| Illustration alone | `aangan-mark-full-colour` (or `-reversed-for-dark-backgrounds`) |
| Small sizes (40–64 px) | `aangan-simplified-tree` |
| Tiny sizes, social avatar | `aangan-monogram`, `aangan-app-icon` |

`-reversed` and `-cream` files are light-coloured: only place them on dark backgrounds (maroon #3C0008 is ideal).

## Favicon tags
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```
`icon-192.png` and `icon-512.png` are for a web app manifest.

## Fonts (for website text, from Google Fonts)
- Headings: **Caprasimo** — caps with 0.04–0.05em letter-spacing.
- Body and labels: **Figtree** (400 body, 700 caps labels with 0.24–0.26em letter-spacing).

## Rules
Keep clear space of ¼ of the logo's width around it. Never stretch, rotate, recolour off-palette, or add shadows/effects.
